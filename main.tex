\section{Atomization energies}
%% ============================================================

We compute atomization energies with several xTC method families and benchmark
them against SHCI+PBE+CV reference values. Per-basis, per-molecule method
discrepancies and the full basis set convergence of error metrics are hosted
as interactive plotly figures~\cite{interactivefigs}.

\begin{figure}[h]
  \centering
  \includegraphics[width=\textwidth]{convergence_vs_shci_pbe.png}
  \caption{Basis set convergence (MAE, RMSE, MaxE in kcal/mol) of atomization
    energy errors vs SHCI+PBE+CV for each method family, on a unified x-axis
    interleaving cc-pV$x$Z and aug-cc-pV$x$Z. The interactive version and
    per-basis per-molecule breakdowns are available
    online~\cite{interactivefigs}.}
\end{figure}
